# Qt Quick 客户端

应用使用 QGuiApplication，全部应用界面由 QML 渲染，不链接 Qt Widgets。已删除旧 QWidget 页面、弹窗、迷你播放器与 `--widgets` 回退入口。C++ 保留资料库、音频、展示模型与系统集成，没有数据库迁移。

主界面、设置、命名/确认弹窗、歌曲信息、右键菜单、文件/文件夹选择和独立迷你播放器都使用 Qt Quick。文件选择强制使用 Qt Quick Dialogs 实现，避免落回 Widgets。macOS 应用菜单、托盘与红绿灯保留 AppKit 系统集成；Windows 托盘使用 Shell_NotifyIcon，Linux 使用 DBus StatusNotifierItem。

弹窗通过带 token 的异步请求与 C++ 交互，连续请求排队，过期回复不会影响后续弹窗。路径选择后的操作捕获原始歌曲/歌单身份，避免在对话框期间改变页面后操作错误对象。

歌曲、专辑、艺术家、文件夹、歌单导航和搜索保留异步查询、过期结果丢弃和可见项复用。重复歌单条目、收藏保护、插播偏好、撤销/重做与原播放核心继续使用已有语义。

播放详情上下滑动；收起时底栏始终留在详情下面。封面放大只作用于固定圆角遮罩内的图像，提示使用共享 EchoToolTip。标题区支持系统拖动与双击缩放。队列面板通过独立展开进度计算位置，窗口缩放时直接跟随右边缘，不再因位置动画追赶窗口而意外露出。

## 验证

`echo-quicktest` 使用随机测试资料库、生成的 WAV 和静音 PCM 输出，检查真实解码、QML 鼠标/键盘交互、弹窗队列/取消、歌单创建、文件选择、歌曲信息、迷你窗口和实际点击定位进度，以及连续窗口缩放。另检查 10,003 首曲目的后台查询、动画帧呈现和播放欠载。不会修改用户资料库或播放测试声音。

2026-10-22 本机最终交互回归：1×/2× 各通过 240 项检查；最新完整界面动画呈现间隔 P95 分别为 8.43 ms、8.73 ms，稳定压力场景 PCM 欠载为零。这是当前显示环境的呈现间隔，不是 GPU 执行耗时，也不代表所有设备表现。

`--qml-smoke` 只执行无需可见 GPU 窗口的场景加载与后台模型检查，供 CI 的 offscreen 环境使用，不替代完整交互与性能检查。旧 Widgets 专用测试目标已移除，CI 对应入口和 Quick 依赖同步更新。

文件夹/队列/不可用文件/废纸篓/PCM 核心集成通过 1943 项检查；自测、播放链路与 macOS 空间音频回归通过。macOS 安装版已实际打开设置、歌单命名、歌曲信息、文件夹选择和迷你播放器，并检查标题栏双击放大。

## 打包与边界

`tools/deploy_macos.py` 只部署 Cocoa、SQLite、图像和 QML 依赖，逐个验证动态依赖，并拒绝任何 Qt Widgets 依赖，最后执行 ad-hoc 签名与校验。当前包含 112 个 Mach-O 文件，产物位于 `output/qml-only-final-20261022/Echo.app`，安装到 `/Applications/Echo.app`。旧版保存在 `build/Echo-before-qml-only-20261022.app`。

Windows/Linux 的源代码和构建配置已更新，但尚未执行对应系统上的原生运行验收。长期功耗、更多外接设备组合和 Developer ID 签名/公证不属于本次验收范围。
